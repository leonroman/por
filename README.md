# Romanian Orthodox Parish of Saint Basil the Great

Website for the Romanian Orthodox Parish of Saint Basil the Great (*Parohia Ortodoxă Română Sfântul Ierarh Vasile cel Mare*), located in Salamanca, Spain.

The purpose of this project is to provide parishioners and visitors with easy access to parish information, service schedules, children’s activities, religious resources, contact details, and donation options.

## Project Overview

The project consists of a responsive website designed to represent the Romanian Orthodox Parish of Saint Basil the Great in Salamanca, Spain.

The website serves as a central point of information for the parish community and visitors, offering a clear and accessible interface for discovering parish activities, schedules, resources, and contact information.

## Main Features

- **Parish Information:** Introduction to the parish and its identity.
- **Parish Schedule:** Information about services and parish activities.
- **Children’s Page:** Content and activities intended for children.
- **Resources:** A dedicated section for religious and parish-related materials.
- **Contact Information:** Details for contacting the parish.
- **Donations:** A dedicated button providing access to donation options.
- **Responsive Navigation:** A mobile-friendly navigation menu for accessing the main sections of the website.

## Main Page Structure

The main page uses a responsive layout designed to provide a consistent user experience across mobile devices and larger screens.

### Header

The header contains the parish branding and the primary navigation control.

Its main elements are:

- A dark blue background.
- The Orthodox Christian parish logo positioned on the left.
- The parish name, *Parohia Ortodoxă Română Sfântul Ierarh Vasile cel Mare*, displayed in white.
- A hamburger menu button on the right, highlighted with a gold background.

### Navigation Menu

When the hamburger menu button is pressed, a full-screen navigation menu appears over a blue-tinted background image of the church.

The menu contains the following links, arranged vertically and centered on the screen:

- **Acasa**
- **Programul Parohiei**
- **Despre Noi**
- **Pagina Copiilor**
- **Resurse**
- **Contact**

The current page, **Acasa**, is highlighted in gold, while the remaining links are displayed in white. A close button is positioned in the upper-right corner to allow users to dismiss the menu.

### Hero Section

The hero section is the main visual element of the homepage. It features a large photograph of the church interior that occupies most of the visible page.

A dark overlay is applied to the image to improve text readability and maintain visual contrast.

The section includes:

- The full parish name, displayed in large, centered white text.
- The location, *Salamanca España*.
- A gold donation button labeled **DONAȚII**, positioned below the title.

This section establishes the website’s visual identity and provides visitors with immediate access to the donation option.

## Visual Design

The website uses a visual style inspired by the parish’s Orthodox Christian identity.

| Element | Description |
|---|---|
| Primary color | Dark blue, used for the header and navigation overlay. |
| Accent color | Gold, used for the active navigation link, menu button, and donation button. |
| Typography | Elegant serif fonts for the parish name and navigation links. |
| Imagery | A prominent photograph of the church interior establishes the visual identity. |
| Layout | Responsive design adapted to mobile devices and larger screens. |
| Contrast | Dark overlays and white text improve readability over background images. |

The overall design aims to create a welcoming, elegant, and consistent experience while keeping the website’s main sections easy to access.
